# TDC documentation

- **[Using TDC](using-tdc.md)** — what the application does, for the people who
  use it.
- **[Moving from Telegram and WhatsApp](moving-from-telegram-and-whatsapp.md)** —
  what a community decides before it moves, how its groups map onto channels,
  and what is better and worse afterwards.
- **[The directory](directory.md)** — profiles somebody chooses to publish,
  companies, and who sees what; switched on by an operator, joined by nobody
  who did not decide to.
- **[Hosting](hosting.md)** — deploying a server, TLS, backup and restore.
- **[Upgrading](upgrading.md)** — moving between releases, including across
  several at once, and what rolling back involves.
- **[Integrating](integrating.md)** — the HTTP API and the live connection, for
  anybody writing a bot, a bridge or another client.
- **[Federation protocol](federation-protocol.md)** — the whole wire protocol:
  discovery, request signing, the event format, replication, and remote
  membership, sufficient to implement the other side without reading this
  source.
- **[Contributing](contributing.md)** — how changes reach this project, what the
  licence requires, and what a pull request has to say.
- **[Privacy policy](privacy-policy.md)** — a template an operator adapts,
  describing what the software actually stores and what leaves the server.
- **[Terms of use](terms-of-use.md)** — a template an operator adapts, covering
  acceptable use, moderation, content ownership and liability.

The repository's [README](../README.md) is the shortest route to a running
server and the reference for what each optional feature costs. The desktop
client has [its own notes](../apps/desktop/README.md).
